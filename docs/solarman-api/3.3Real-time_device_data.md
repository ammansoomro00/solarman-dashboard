
# Introduction
This interface provides the data you see in the Solarman platform device details page, and the interface provides data access channels.

# FAQ
1. How to get the table of data points
    1. This interface has returned a point table of data.
        1. Key: Parameter key
        2. value: Parameter values
        3. unit: Parameter units
        4. name: The name of the parameter

# Interface Details

POST /device/v1.0/currentData

> Body Request Parameters

```json
{
  "deviceSn": "string"
}
```

### Request Parameters
| Name | Location | Type | Required | Description |
| :---: | :---: | :---: | :---: | :---: |
| language | query | string | Yes | Language type, example value: zh |
| Authorization | header | string | Yes | accessToken, example value: bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9 |
| body | body | object | No | none |
| » deviceSn | body | string | Yes | Device serial number, example value: 200124137 |
| » deviceId | body | int | No | Unique identification of the device within the platform<br/>If deviceId is passed, the value of deviceId takes precedence and deviceSN is ignored.<br/>Note: deviceSN is required |

### PYTHON
```python
# Install the Python Requests library:
# `pip install requests`

import requests
import json

def send_request():
    # 3.3 Real-time Data-Device
    # POST https://api.solarmanpv.com/device/v1.0/currentData

    try:
        response = requests.post(
            url="https://api.solarmanpv.com/device/v1.0/currentData",
            params={
                "language": "zh",
            },
            headers={
                "Content-Type": "application/json",
                "Authorization": "bearer your-token",
            },
            data=json.dumps({
                "deviceSn": "deviceSn"
            })
        )
        print(f'Response HTTP Status Code: {response.status_code}')
        print(f'Response HTTP Response Body: {response.content}')
    except requests.exceptions.RequestException:
        print('HTTP Request failed')
```
